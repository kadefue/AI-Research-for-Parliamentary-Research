\chapter{Morning Session: The Zero-Copy AI Ingestion Paradigm}

\section{Why Manual Copy-Pasting Compromises Parliamentary Work}
Parliamentary researchers and clerks regularly handle files with thousands of paragraphs and dense statistical exhibits. The conventional habit of manually highlighting and copying text into a separate editor introduces severe operational hazards:
\begin{enumerate}
    \item \textbf{Truncation and Omission:} Critical statutory qualifiers (such as \textit{"subject to the prior written approval of the Minister"} or \textit{"provided that expenditure shall not exceed 10\%"}) are frequently missed during manual copying.
    \item \textbf{Scrambled Tabular Data:} Highlighting tables in PDF files copies characters in visual order rather than tabular structure, scrambling numbers, column headers, and totals.
    \item \textbf{Version Instability:} Copying back and forth between different versions of Microsoft Word corrupts margins, numbering schemes, and font hierarchies.
\end{enumerate}

\section{Guiding Principles for Direct AI Querying}
To safeguard parliamentary integrity, participants must follow three rules:
\begin{itemize}[label=-]
    \item \textbf{Explicit File Grounding:} Every AI prompt must explicitly reference the file name (e.g., \texttt{@documents/national\_water\_policy.pdf}). Never ask broad, ungrounded questions like \textit{"Tell me about water policy in Tanzania."}
    \item \textbf{Strict Text Boundary Injection:} Always instruct the model: \textit{"Rely exclusively on the referenced file. If a figure or provision is not in the document, state 'Not Found in Source' rather than inferring."}
    \item \textbf{Reproducible Output Commands:} Command the AI to output clean Markdown code blocks that can be saved directly into your reports folder with a single click.
\end{itemize}

\subsection{Action Item 1: Creating the Workspace Directory}
\begin{enumerate}[label=\textbf{Step \arabic*:}]
    \item Open Visual Studio Code.
    \item From the top menu, select \textbf{File $\rightarrow$ Open Folder...}
    \item Navigate to your \textbf{Documents} folder. Click \textbf{New Folder}, name it \texttt{Parliamentary\_Research\_2026}, and click \textbf{Select Folder}.
    \item When prompted with \textit{"Do you trust the authors of the files in this folder?"}, select \textbf{Yes, I trust the authors}.
    \item In the VS Code File Explorer (left pane), click the \textbf{New Folder} icon and create:
    \begin{itemize}[label=-]
        \item \texttt{documents}
        \item \texttt{briefs\_and\_reports}
    \end{itemize}
\end{enumerate}

\subsection{Action Item 2: Installing Essential Non-Programmer Extensions}
Click the Extensions icon on the left Activity Bar (\texttt{Ctrl + Shift + X}) and install:
\begin{enumerate}
    \item \textbf{Markdown All in One:} For text formatting, lists, and heading shortcuts.
    \item \textbf{Markdown PDF:} For one-click export of Markdown documents to executive PDF.
    \item \textbf{AI Assistant (Continue / GitHub Copilot):} For querying native workspace files directly.
\end{enumerate}

\section{The Direct File Drop: Native Word and PDF Ingestion}
Trainees will now ingest their documents without opening Word or Adobe Acrobat:
\begin{enumerate}[label=\textbf{Step \arabic*:}]
    \item Open your computer's regular File Explorer (Windows Explorer or macOS Finder).
    \item Locate your native Word file (e.g., \texttt{ministerial\_memo.docx}) and your native PDF file (e.g., \texttt{sector\_report.pdf}).
    \item Drag and drop both files directly into the \texttt{documents} folder inside the VS Code File Explorer.
    \item Both files are now situated in your workspace, fully indexed and ready for AI interrogation. No copying. No pasting. No re-typing.
\end{enumerate}

\section{Training the AI to Ingest Native Files Directly}
Open the AI Assistant sidebar in VS Code. We will now execute our first direct file interrogation prompts:

\subsection{Querying a Native Word Document (\texttt{.docx})}
Type the following prompt directly into the AI sidebar:
\begin{quote}
\small
\textit{"Examine @documents/ministerial\_memo.docx directly. Do not require me to paste any text. \\
1. Extract the core policy objective stated by the executive. \\
2. Extract all stated budgetary allocations, target figures, and project deadlines into a clean Markdown table. \\
3. Highlight any operational risks or ambiguities mentioned in the text. \\
Rely strictly on this file. Present your response in clean Markdown."}
\end{quote}

\subsection{Querying a Native PDF Document (\texttt{.pdf})}
Now query your native PDF report:
\begin{quote}
\small
\textit{"Read @documents/sector\_report.pdf directly. Scan the document for all quantitative tables regarding regional performance. \\
Extract the regional targets, reported achievements, and calculate the delivery variance. Format the output as a 4-column Markdown table. Do not summarize in prose; provide the exact figures."}
\end{quote}

Notice the efficiency: In less than ten seconds, the AI reads through multi-page native files, parses tables, calculates variances, and outputs structured Markdown text ready for your parliamentary brief.
